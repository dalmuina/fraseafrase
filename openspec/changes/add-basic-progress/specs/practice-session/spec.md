# Spec Delta

## REMOVED Requirements

### Requirement: Pantalla de práctica como inicio

**Reason**: Qué pantalla se muestra al abrir la app pasa a depender de la pestaña inicial de la
barra de navegación inferior, no de la pantalla de práctica en sí (`app-navigation`).

**Migration**: Usar el requisito "Pestaña de práctica como inicio" de `app-navigation`.
